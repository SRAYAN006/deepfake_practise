# 🛡️ DeepGuard – AI-Powered Deepfake Image Detection

DeepGuard is a modern web application that helps users identify whether an uploaded image is real or AI-generated (deepfake). The application performs image analysis, extracts visual features, and provides an easy-to-understand authenticity report through an interactive interface.

---

## 📌 Features

- 🖼️ Upload images (JPG, PNG, WebP)
- 🤖 AI-based deepfake detection
- 📊 Confidence score and authenticity prediction
- 📈 RGB histogram visualization
- 🔍 Pixel-level difference analysis
- 📄 Export analysis report as JSON
- 🖨️ Print-friendly report generation
- 🌙 Dark and Light mode
- 📱 Responsive UI for desktop and mobile

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/SRAYAN006/deepguard.git
```

Go to the project folder

```bash
cd deepguard
```

Start a local server

Using Python

```bash
python -m http.server 8000
```

Open your browser

```
http://localhost:8000
```

---

## 📖 How to Use

1. Open the application.
2. Upload an image.
3. Click **Analyze**.
4. Wait for the AI model to process the image.
5. View:
   - Prediction
   - Confidence Score
   - Trust Score
   - RGB Histogram
   - Pixel Analysis
6. Export or print the report.
